# ATS Guidelines (knowledge/ATS.md)

This document contains standardized guidelines to ensure the candidate's CV is optimized for Applicant Tracking Systems (ATS).

## 1. Document Structure & Layout
* **Single Column Format:** Prefer a clean, single-column layout for work experience and projects. Grids should only be used for Technical Skills.
* **Standard Section Titles:** Use standard headings recognized by ATS parsers:
  * "Summary" or "Professional Summary"
  * "Work Experience" or "Professional Experience"
  * "Projects" or "Technical Projects"
  * "Technical Skills" or "Skills"
  * "Education" or "Education & Qualifications"

## 2. Text and Keywords
* **Standard Fonts:** Use standard, web-safe, or modern academic fonts (e.g., New Computer Modern or DejaVu Serif). Avoid symbols or custom dingbats that might corrupt text parsing.
* **ATS Keyword Density:** Focus on reflecting terms from the Job Description (JD) naturally. Prioritize must-have technical skills (e.g., specific libraries, languages, tools) in the Technical Skills grid and Summary.
* **No Image Text:** Never use scanned images or non-selectable text for CV content. Typst output must yield clean, selectable Unicode text.
